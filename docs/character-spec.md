# 小待角色设定 v1（阶段 B）

以 `character-lab/design-board.html` 为可视设定板，`js/xiaodai-art.js` 为唯一静态轮廓数据。256×256 画布，透明背景；白色微暖身体、淡灰绿接触阴影、淡黄纸便签、深青灰面部线条。只用少量平涂，不用塑料高光、写实毛发、复杂渐变。正面主体宽约 172、高约 137 单位；头顶便签宽 78、高 56；肩锚点在 (62,164) / (194,164)，脚在 (91,224) / (165,224)，落地阴影中心 (128,241)。脸位于同一身体坐标系，眼中心 (105,150) / (151,150)，嘴 (128,177)。

| 视角 | 轮廓和遮挡规则 |
| --- | --- |
| 正面 | 双眼等宽，两手对称露出，双脚同一地面。 |
| 左 / 右 ¾ | 独立体型轮廓，远眼更窄；远手在身体之后，近手在身体之前。便签轻微横移。 |
| 左 / 右侧面 | 单眼可见，远手在身体后；便签以纸边表现。绝不用正面水平压缩代替。 |
| 背面 | 无面部、便签背面无字；身体下缘完整连续。没有尾巴，也没有尾状装饰。 |

表情：neutral（稳定眼与浅笑）；happy（弯眼、张口、放松）；curious（眉上扬、斜视、偏嘴）；confused（不对称眉与嘴）；sleepy（低眼皮、细嘴）；surprised（睁眼与圆口）；sad（内收眉与下弯嘴）；determined（聚焦眉与平直嘴）。每一种表情的静态姿态已在设定板中单独显示，后续动作进入和退出以时间轴过渡。

关键姿势：stand、notice、curious、remind、encourage、firm、hop、celebrate。前六个维持接地；hop 和 celebrate 提升身体并缩小地面阴影。姿势只是静态关键帧，不能代替动作编排。动作阶段需要先注意、预备、主动作、跟随超调、恢复。弯曲或旋转手臂都绕肩部锚点，便签绕下缘 (128,97) 摇动。动作时脚和手须根据遮挡层留在正确侧别。阴影永远在角色之后。

任何视角都不得出现尾巴或疑似尾巴结构。转身只允许使用设计好的正面、三分之四、侧面和背面，不做横向缩放伪装三维旋转。未来若需要更大动作，应先补新的关键视角轮廓。
