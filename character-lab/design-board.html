04 / KEY POSES

八个有意图的姿势

先看关键姿势是否清楚。阶段 D 才把姿势连接成有预备、超调和恢复的动作。

ANCHORS

共同坐标

肩 (62,164) / (194,164)；眼 (105,150) / (151,150)；便签 (128,97)；脚 (91,224) / (165,224)。局部动作以这些点为轴。

OCCLUSION

前后关系

阴影 → 双脚 → 远手 → 身体 → 近手 → 面部 → 便签。背面只保留身体、四肢与便签背面，不画眼或嘴。

NO TAIL

背面与侧面

臀部保持连续圆弧；任何手脚、装饰或影子都不得从后下方形成尾状突出。较大转身只换正式视角造型。
